# Setup SSL for NGINX

The system administrators at xFusionCorp Industries need to prepare **App Server 3** in the Stratos Datacenter for a new application.

## Requirements

1. Install and configure NGINX on App Server 3.
2. Deploy the self-signed certificate and key currently at `/tmp/nautilus.crt` and `/tmp/nautilus.key`.
3. Create `/usr/share/nginx/html/index.html` with the content `Welcome!`.
4. From the jump host, verify HTTPS with `curl -Ik https://<app-server-ip>/`.

## Solution

1. Connect to App Server 3 and install NGINX.

    ```sh
    sudo yum install -y nginx
    ```

2. Create the application landing page.

    ```sh
    echo 'Welcome!' | sudo tee /usr/share/nginx/html/index.html > /dev/null
    ```

3. Move the certificate and private key to standard system locations. Restrict access to the private key.

    ```sh
    sudo mkdir -p /etc/pki/tls/certs /etc/pki/tls/private
    sudo mv /tmp/nautilus.crt /etc/pki/tls/certs/nautilus.crt
    sudo mv /tmp/nautilus.key /etc/pki/tls/private/nautilus.key
    sudo chmod 600 /etc/pki/tls/private/nautilus.key
    ```

4. Create an HTTPS virtual-host configuration at `/etc/nginx/conf.d/ssl.conf`.

    ```nginx
    server {
        listen 443 ssl;
        server_name _;

        root /usr/share/nginx/html;
        index index.html;

        ssl_certificate     /etc/pki/tls/certs/nautilus.crt;
        ssl_certificate_key /etc/pki/tls/private/nautilus.key;

        location / {
            try_files $uri $uri/ =404;
        }
    }
    ```

5. Validate the configuration, then enable and start NGINX.

    ```sh
    sudo nginx -t
    sudo systemctl enable --now nginx
    ```

6. From the jump host, verify the HTTPS endpoint. `-k` is required because the certificate is self-signed; `-I` returns the response headers only.

    ```sh
    curl -Ik https://stapp03/
    ```

    A successful response includes `HTTP/1.1 200 OK`.

## Good to Know

- `ssl_certificate` points to the public certificate; `ssl_certificate_key` points to its matching private key.
- Test every NGINX change with `nginx -t` before reloading or restarting the service.
- Use `curl -k` only for testing self-signed certificates. Production certificates should be issued by a trusted certificate authority.
- The private key should never be publicly readable; mode `600` limits it to its owner.
